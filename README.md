# Nowa strona WLB – makieta

Propozycja nowej strony [Warszawskiej Ligi Biegowej](https://www.warszawskaligabiegowa.pl/).

Podgląd: https://przemowakcji.github.io/wlb-nowa-strona/

To makieta: formularz kontaktowy nie wysyła wiadomości, a część linków prowadzi na obecną stronę.
Strona ma `noindex`, więc nie pojawi się w wyszukiwarkach.

Zdjęcia pochodzą z obecnej strony WLB, logotypy ze stron organizatorów i partnerów.
